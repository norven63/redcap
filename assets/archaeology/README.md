# Archaeology Layer

Purpose: controlled access to old RedCap reference material.

Belongs here:

- source maps into the old repository
- extraction notes
- migration inventories
- exact-path references

Does not belong here:

- copied old task reports by default
- copied raw `prism/runs`
- copied closeout receipts
- old `.dev-task.md` state

Rule: ask a specific question, open exact sources, stop when the question is
answered.
