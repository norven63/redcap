### L-5: Agent 超时应优先从自身调用方式排查
- **场景**：多次调用 Agent 超时，初步判断为 Agent 工具质量问题
- **根因**：实际多为 Prompt 过长、交互式阻塞（sandbox 确认、权限确认）、工作目录错误等自身调用问题
- **经验规则**：Agent 超时时按以下顺序排查：Prompt 长度 → 交互式阻塞参数 → 工作目录 → Session 恢复 → 网络代理 → 最后才怀疑 Agent 工具质量
