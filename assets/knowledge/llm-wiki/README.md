# LLM-wiki-lite private memory

This directory is RedCap's private, non-authoritative semantic-memory store.

It is not a public wiki, not a source of truth, and not a replacement for
`.dev-task.md`, policy JSON, closeout receipts, Prism acceptance, commits,
or source-path-preserving retrieval.

Use `compass/tools/redcap-llm-wiki-lite-check.sh` before trusting entries.
The checker rejects entries with stale source anchors, unsafe public promotion
claims, unsupported candidate types, or raw private evidence in the body.
